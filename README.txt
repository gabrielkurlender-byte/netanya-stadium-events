אתר חינמי להצגת משחקים, הופעות ואירועים גדולים באצטדיון מרים.
פרסום חינמי: צור מאגר GitHub ציבורי, העלה את ארבעת הקבצים, וב-Settings > Pages בחר Deploy from a branch, main, /root. המתן לקבלת קישור.
האתר אינו מושך אירועים אוטומטית. כדי להוסיף אירוע מאומת, ערוך את events.json, למשל:
{"updated":"2026-10-13","events":[{"title":"שם האירוע","date":"2026-11-01T20:00:00+02:00","type":"משחק","source":"https://example.com/official-event"}]}
יש להזין רק אירועים שנבדקו שמתקיימים בתוך האצטדיון עצמו. אל תכלול אירועים בארנה הסמוכה או בעסקים במתחם.
